# Dataset Directory

This directory contains the League of Legends ranked match telemetry datasets sourced from Zenodo.

- **Source:** Zenodo (DOI: [10.5281/zenodo.8303397](https://doi.org/10.5281/zenodo.8303397))
- **Time period:** January 12 – May 18, 2023
- **Coverage:** Ranked matches from Iron to Diamond tiers

## File Descriptions

| File | Description | Size | Rows | Columns |
| :--- | :--- | :--- | :--- | :--- |
| `raw/full_data_20.csv` | Match snapshot at 20% match duration | ~8.3 MB | ~64,556 | 42 |
| `raw/full_data_40.csv` | Match snapshot at 40% match duration | ~8.6 MB | ~64,556 | 42 |
| `raw/full_data_60.csv` | Match snapshot at 60% match duration | ~8.7 MB | ~64,556 | 42 |
| `raw/full_data_80.csv` | Match snapshot at 80% match duration | ~8.8 MB | ~64,556 | 42 |
| `raw/full_data_100.csv` | Match snapshot at 100% (final match state) | ~8.9 MB | ~64,556 | 42 |
